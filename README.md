# 🐍 Snake Game using Python

A classic Snake Game developed using Python and the Turtle graphics module.

## 📌 About the Project

This is a simple Snake Game where the player controls a snake, eats food, and tries to achieve the highest score without hitting the walls or its own body.

## 🚀 Features

- Snake movement using keyboard controls.
- Food generation at random positions.
- Score tracking.
- Game over detection.
- Collision detection with walls and snake body.

## 🛠️ Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)

## 📂 Project Structure

snake-game/

## ▶️ How to Run

1. Install Python on your computer.
2. Clone this repository:

```bash
git clone https://github.com/waheed2117/snake-game.git
```

3. Open the project folder.
4. Run the game:

```bash
python main.py
```

## 🎮 Controls

- Up Arrow – Move Up
- Down Arrow – Move Down
- Left Arrow – Move Left
- Right Arrow – Move Right
